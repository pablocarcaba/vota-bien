- [x] **Subsidio de mayores de 52** (121/000027, 130/000005): ¿añadir `adultos`? → **Decidido: se añade `+adultos` (rúbrica 3.7).**
- [x] **Bienestar animal**: 122/000202 (pulpos) `-secPrim`; 122/000046 (protección animal) vacía. → **Se mantiene como está.**
- [x] **Deepfakes e IA** (122/000011, 122/000073): vacías; una opción es `-secDig`. → **Se mantiene como está.**
- [x] **Embargo de armas** (121/000070, Gaza): vacía como política exterior; las otras leyes de armas (122/000111, 122/000122) llevan `-secInd`. → **Se mantiene como está.**
- [x] **Medicamentos y tabaco**: 121/000109 y 122/000198 `-secInd` (farmacéutica); 121/000110 `-secCom` y `-secInd`. → **Se mantiene como está.**
